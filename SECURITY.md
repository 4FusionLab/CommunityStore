# Security policy

[Русская версия](SECURITY.ru.md)

Please do not publish vulnerabilities, secrets, license keys, customer models, or unredacted diagnostic logs in public issues.

For vulnerabilities or sensitive concerns about add-ins and sources distributed through Community Store, use [GitHub Security Advisories](https://github.com/4FusionLab/CommunityStore/security/advisories) and select **Report a vulnerability** if available. You can also email the [4FusionLab organization contact](mailto:4fl@pkuz.ru) privately. Include the affected versions, steps to reproduce and impact. Ask for a secure way to share sensitive attachments if needed.

The project intentionally rejects likely secret files and symlinks during packaging. This check is not a substitute for code review or real Autodesk Fusion testing.
