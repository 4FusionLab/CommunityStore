# Community Store 1.0.0 for Autodesk Fusion

Browse GitHub add-in releases, install compatible packages, and manage registered add-ins directly in Fusion. The catalog works without a GitHub account and is available in English and Russian.

- Add a GitHub user or organization to **Marketplace → Sources** to discover its published add-ins.
- In **My Add-ins**, link existing folders, manage startup, choose a target version, and preview updates. Store keeps backups of the add-ins it updates.
- To install, download **CommunityStore-1.0.0.zip** from the release assets and extract it to a permanent folder. In **Utilities → Add-Ins → Scripts and Add-Ins**, add the extracted **CommunityStore** folder, select **Run**, and enable **Run on Startup**. The command appears in the Design workspace's **Add-Ins** panel.

The ZIP includes the PolyForm Noncommercial License 1.0.0. Previous builds were exercised in Fusion 2706.1.17 on macOS. Native Fusion testing on Windows x64 remains open. ## По-русски

Community Store позволяет искать аддины на GitHub, устанавливать совместимые пакеты и управлять подключёнными аддинами прямо в Fusion. Каталог работает без аккаунта GitHub, на русском и английском языках.

- Добавьте пользователя или организацию GitHub в **Каталог → Источники**, чтобы видеть опубликованные ими аддины.
- В разделе **Мои аддины** можно подключать папки, управлять автозапуском, выбирать целевую версию и проверять список предстоящих обновлений. При обновлении аддина Store сохраняет резервную копию.
- Для установки скачайте **CommunityStore-1.0.0.zip** из файлов релиза и распакуйте в постоянную папку. В **Utilities → Add-Ins → Scripts and Add-Ins** добавьте извлечённую папку **CommunityStore**, нажмите **Run** и включите **Run on Startup**. Команда появится на панели **Add-Ins** в рабочей области Design.
