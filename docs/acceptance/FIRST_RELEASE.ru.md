# Решение по первому релизу

[English](FIRST_RELEASE.md)

## Проверка 1.0.0 в Fusion на macOS

Проверен ZIP версии 1.0.0 с SHA-256 `4f843a0a6fb19c85501f39c1e70c672de8a0c242773e672facc2abe23a362e2a`. Все 48 файлов установленного кода, ресурсов и манифеста совпали с содержимым ZIP побайтно. В открытом сеансе Fusion 2706.1.17 на macOS 27.0.1 arm64 аддин остановили и снова запустили из существующей регистрации. Контроллер показал версию 1.0.0, команда открыла палитру с заполненным списком установленных аддинов. **Run on Startup** был включён. Документ Fusion сохранил состояние без несохранённых изменений.

Это проверка перезапуска аддина в текущем сеансе. Установка в чистый профиль и полный перезапуск Fusion описаны ниже для более ранних кандидатов. Нативная проверка на Windows x64 остаётся открытой.

## Кандидат для сообщества Windows x64

**Кандидат 0.2.0 готов к передаче на нативную проверку в Fusion для Windows x64.** SHA-256 установочного ZIP `4b2004162db0dec62fc1c4649fc61c1af33040aae3a176454ea050c0c3e37536`. В комплект входят архив, контрольная сумма и инструкции RU/EN. [Сценарии и форма отчёта](WINDOWS_COMMUNITY.ru.md)

На macOS пройдены 111 из 115 офлайн-тестов на каждой из версий Python 3.12 и 3.14. Пропущены три теста для Windows и один тест шаблона. В Chrome прошли 20 тестов палитры. Код из распакованного кандидата в режиме выбора Windows скачал и проверил по SHA-256 три публичных ZIP, распаковал их и нашёл входные файлы ACDC4Robot 1.1.0, 1.1.1 и Gridfinity 2.0.0. Регистрация и запуск этих пакетов в Windows Fusion, поведение NTFS при занятом файле и восстановление входа через Windows Credential Manager ожидают проверки сообществом. Нативные результаты macOS ниже относятся к указанным там сборкам.

## Полная визуальная приёмка на macOS

**Интерфейс кандидата 0.2.0 прошёл визуальную приёмку в Fusion 2706.1.17 на macOS 27.0.1.** SHA-256 `c2a295e45c20bb07d7ae4084b1dfb3476213b99a822f2feddb0f42d4b0d1e541`.

В изолированной палитре проверены 41 экран и состояние на русском и английском, в светлой и тёмной темах. Для каждого из 164 сочетаний сохранены два снимка. Использованы одинаковые тестовые данные. Обычная ширина содержимого составила 314 CSS px. Для двух компактных сценариев использовался фрейм шириной 300 CSS px в той же палитре. На всех 164 итоговых кадрах WebView принял тему от macOS. Уже открытый WebView сохранял прежнее оформление до пересоздания.

Системные окна выбора папки и сохранения журнала открыты и отменены в обеих темах для обоих языков Store. Файлы и регистрации сохранились. После перезапуска только аддина штатная палитра загрузила обновлённые подписи из рабочего checkout. Вход в GitHub и автозапуск сохранились.

Устранены переносы и смещения в списке версий, недочёты меню и клавиатурного фокуса, подписи и группировка действий в диалогах. Браузерная проверка добавила 492 кадра итоговой сборки и 20 тестов. В офлайн-прогоне из 92 тестов прошёл 91, один тест шаблона пропущен. В ZIP изменились пять файлов интерфейса и локализации. Предыдущие нативные проверки установки, сохранности и GitHub относятся к указанным ниже сборкам.

В изолированной нативной палитре Fusion 2706.1.17 обе кнопки открыли выбор версии, сохранение v0.0.2 обновило строку и тестовый профиль. От предыдущего ZIP отличаются три файла палитры.
