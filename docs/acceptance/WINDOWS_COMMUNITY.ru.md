# Проверка Community Store в Fusion для Windows

[English](WINDOWS_COMMUNITY.md)

Это инструкция для проверки релизного ZIP в Fusion для Windows x64. Для установки достаточно Fusion, ZIP Community Store и файла контрольной суммы. Python отдельно устанавливать не требуется. Для операций с установкой, обновлением и удалением выберите тестовые аддины.

## Установка

1. Скачайте из [релиза 1.0.0](https://github.com/4FusionLab/CommunityStore/releases/tag/v1.0.0) ZIP и соответствующий файл `.zip.sha256` в одну папку. Откройте в ней PowerShell и выполните команды ниже. При несовпадении сумм используйте новую копию архива.
2. В Проводнике выберите **Извлечь всё** и распакуйте архив в постоянную папку внутри своего профиля с правом записи. Можно выбрать путь с пробелами и кириллицей. Внутри папки `CommunityStore` должны находиться рядом `CommunityStore.py` и `CommunityStore.manifest`.
3. В Fusion откройте **Utilities → Add-Ins → Scripts and Add-Ins**. Добавьте именно папку с манифестом, нажмите **Run** и включите **Run on Startup**. Откройте **Community Store** в панели **Add-Ins** рабочей области Design.

```powershell
$zip = ".\CommunityStore-1.0.0.zip"
$expected = ((Get-Content "$zip.sha256" -Raw).Trim() -split '\s+')[0]
(Get-FileHash $zip -Algorithm SHA256).Hash -eq $expected
```

Ожидаемый результат в PowerShell — `True`.

## Что проверить

| Сценарий | Ожидаемый результат |
|---|---|
| Первый запуск без GitHub | Руководство открывается. После завершения в **Каталоге** можно искать аддины, открывать карточки и устанавливать совместимый релиз без входа. |
| Кастомные источники | Через **Источники** добавьте публичную организацию и пользователя GitHub с релизами аддинов. Примеры — `ACDC4Robot` и `906grown`. Появляются их карточки. Установите тестовый аддин, удалите его источник и проверьте, что аддин остаётся в **Моих аддинах**. |
| Windows-пакет и обновление | Для пакета с несколькими ZIP проверьте выбор Windows-варианта. Установите ACDC4Robot из каталога. В **Моих аддинах** выберите целевую версию v1.1.0 и примените изменение, если оно требуется. Когда установленная версия станет 1.1.0, выберите v1.1.1 и примените обновление. Проверьте версию, запуск, автозапуск и резервную копию прежней управляемой папки. Для **Обновить выбранные** выберите два тестовых аддина и сверьте предварительный список с итогом по каждой строке. |
| Перезапуск и самообновление Store | Перезапустите Fusion с включённым автозапуском. Зарегистрированный Store открывается с прежними настройками. Если Store предложит новую опубликованную версию, подготовьте обновление, перезапустите по подсказке и запишите обе версии. Если новой версии нет, отметьте самообновление как непроверенное. |
| Занятый файл | Для управляемой тестовой установки проверьте обновление при открытом с исключительной блокировкой файле в старой папке. Если Windows отклонила операцию, прежние файлы должны сохраниться, а Store должен сообщить результат. Освободите файл и повторите. Фиксируйте, произошёл ли реальный отказ. |
| Локальная папка и управление | Подключите тестовый аддин из папки с пробелами и кириллицей. Проверьте запуск, остановку, открытие в Проводнике и автозапуск. После отвязки проверьте исходные файлы. Для архивированного аддина проверьте **Восстановление из архива → Открыть архив**. |
| Вход и перезапуск | В **Настройках** начните вход в GitHub, скопируйте код кнопкой и подтвердите в браузере. Перезапустите Fusion. Store запускается один раз, настройки, источники и профиль GitHub сохраняются. После выхода снова доступен анонимный каталог. |
| Палитра и диагностика | Проверьте RU/EN, светлую и тёмную темы, узкую палитру, Tab, Enter и Escape. После смены темы проверяйте также заново открытую палитру. **Настройки → Выгрузить логи…** открывает выбор файла и сохраняет ZIP. |

Для проверки занятого файла используйте временную установку ACDC4Robot v1.1.0. Откройте PowerShell в папке установленного аддина. Оставьте окно открытым и попробуйте обновить аддин в Fusion.

```powershell
$folder = (Get-Item -LiteralPath ".\ACDC4Robot.manifest").DirectoryName
$probe = Join-Path $folder ("lock-test-" + [guid]::NewGuid() + ".tmp")
$lock = [System.IO.File]::Open($probe, 'CreateNew', 'ReadWrite', 'None')
```

Выполните `$lock.Dispose()` в том же окне и повторите обновление. В зависимости от блокировки Windows может разрешить переименование родительской папки. Укажите фактический результат.

## Как сообщить результат

Укажите версию и сборку Windows, архитектуру, версию Fusion, SHA-256 Store, источник/тег тестового аддина и точное имя выбранного ZIP. Для проблемы приложите шаги, ожидаемый и фактический результат, текст ошибки и скриншот. При неудачном обновлении укажите также версии, состояния запуска и наличие резервной копии. Если палитра недоступна, журналы лежат в `%LOCALAPPDATA%\4FusionLab\CommunityStore\Logs`. Перед отправкой исключите из вложений коды GitHub и личные данные.
